MANDATORY

1. Hard Constraints (0% Tolerance for Clashes)

Faculty Anti-Clash Rule

A professor can never be assigned to teach in two different rooms or sections at the exact same period.

Room Anti-Clash Rule

A classroom or physical laboratory can never be double-booked by two different classes at the same time.

Section Anti-Clash Rule

A student section (e.g. CS-1 2nd Year) can only attend one lecture or lab at any given period.

Protected Lunch Break

Period 5 (12:50 PM - 01:40 PM) is locked as a universal lunch break for all students and faculty.

Facility Type Matching

Practical lab courses are strictly assigned to physical laboratories; theory lectures are assigned to standard classrooms.

OPTIMIZATION

2. Soft Constraints (Quality & Workload Balancing)

Even Weekly Workload Spread

Spreads lectures evenly across Mon-Sat instead of crowding all teaching hours into 1-2 heavy days.

Consecutive Hours Cap

Prevents assigning more than 3 continuous teaching hours to a professor without a break.

Continuous Lab Block Grouping

Practical labs (PR = 4 hrs) are automatically bundled into back-to-back blocks (P1-P3 or P5-P7).

Idle Gap Minimization

Minimizes long vacant periods between classes for both students and faculty.

ENGINE ARCHITECTURE

3. Underlying Core Technology & AI Subsystems

Google OR-Tools CP-SAT Solver

Mathematical Constraint Programming engine that models all weekly classes into boolean integer equations to calculate 100% clash-free schedules in seconds.

Self-Contained AI (0 External API Keys)

Runs 100% locally on your server without requiring any external paid API keys (OpenAI / Claude). Ensures 0 monthly cost and total student/faculty data privacy.

Natural Language Intent Parser

Extracts faculty names, sections, days, and periods from conversational prompts with token-based fuzzy matching to handle typos and initials.

Live Database Real-Time Sync

Queries the live SQLite / PostgreSQL master table on every request, ensuring Section, Faculty, and Room timetables are always 100% in sync.

INSTITUTIONAL FEATURES

4. Advanced Features & Export System

Dynamic Excel Parser (.xlsx / .csv)

Parses faculty workloads, weekly theory/lab hours (TH/PR), and maps semester codes (e.g. AL306 -> 2nd Year, AL702 -> 4th Year) automatically from any Excel file.

Parallel Multi-Batch Scheduling

Splits large student sections (60 students) into sub-batches (Batch B1 & Batch B2) and schedules simultaneous labs in separate rooms without clashes.

1-Click PDF & Word Export

Generates print-ready formatted PDFs for notice boards and Word (.docx) files for HOD records across Section, Faculty, and Room views.

Historical Revision Tracking

Supports mid-semester timetable revisions with effective date versioning (e.g. 2024-09-30 vs 2024-11-18) without overwriting past schedules.

Interactive Manual Grid Override

Click any period on the visual grid to manually edit, swap rooms, or delete slots with real-time automatic conflict re-validation.

Synchronized Visual Focus

When asking the AI assistant about a faculty or section, the system automatically focuses and displays their timetable on the visual grid in real time.
